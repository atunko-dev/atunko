## Purpose

Provide recipe source classification and filtering — every catalog recipe is classified as BUNDLED or USER (user recipe jars loaded via a jar-aware environment, with honest classification for name collisions), filterable via `--source <all|bundled|user>` on `list`/`search` and the `u` source-toggle key in the TUI browser.
